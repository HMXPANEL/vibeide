LICENSING NOTE:

The PRoot library (GPL-2.0) is loaded as a shared library (libproot.so) at
runtime via System.loadLibrary(). The VibeIDE application code (MIT/GPL-3.0)
dynamically links to PRoot. This is generally considered a separate work
under the GPL, but legal review is recommended for production distribution.

The talloc library (LGPL-3.0) is also dynamically linked as a shared library.

The libandroid-shmem library (BSD-3-Clause) is dynamically linked.

All third-party licenses are preserved in core/app/src/main/assets/licenses/.
